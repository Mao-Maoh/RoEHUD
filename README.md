# RoEHUD

[English](README.md) | [日本語](README_ja.md)

RoEHUD is an unofficial Windower 4 addon for FINAL FANTASY XI. It provides a
compact Records of Eminence HUD, objective details, and recommendations based
on conditions such as your current zone, jobs, day, and weather.

## Installation

1. Place the `RoEHUD` folder in your Windower `addons` directory.
2. Start FINAL FANTASY XI through Windower.
3. Load the addon:

```text
//lua l RoEHUD
```

To reload it after an update:

```text
//lua r RoEHUD
```

## Basic Use

Open or close the menu with:

```text
//rh menu
```

Choose **Manual** from the in-game menu for controls, configuration, HUD
layout, sound settings, and other detailed instructions.

RoEHUD supports Japanese and English. The language can be changed from
**Config** or with `//rh lang`.
